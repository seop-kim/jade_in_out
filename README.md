# Jade 출퇴근 기록 · 신규 인사시스템

Jade 출퇴근 기록과 신규 인사시스템의 휴가·근태 정보를 한 화면에서 확인할 수 있는 개인용 React 웹 앱입니다.

기존 시스템과 신규 인사시스템은 상단 탭으로 분리되어 있으며, 각각의 인증 정보와 조회 상태도 독립적으로 관리됩니다.

> 보안을 위해 실제 API 주소, 요청 필드 값, Cookie, Request Body 등의 운영 값은 이 문서에 기록하지 않습니다. 로컬 환경변수 또는 Vercel 프로젝트 환경변수에만 입력하세요.

## 주요 기능

### 기존 시스템(Jade)

- 월간 출퇴근 캘린더
- 출근·퇴근·연장근무·휴가·휴일근무 표시
- 출근/퇴근 변경 및 누락 상태 표시
- 자동인증과 수동인증 지원
- cURL 붙여넣기를 통한 Cookie와 Request Body 자동 파싱
- 날짜 조회 중 진행 상태 표시 및 중복 요청 방지

### 신규 인사시스템

- 기존 시스템과 분리된 신규 탭
- 자동인증: 로그인된 신규 인사시스템 창과 북마클릿으로 연결
- 수동인증: Cookie를 직접 입력
- 월간 팀 일정, 부서 연차, 본인 연차, 출퇴근 기록 조회
- 휴일 및 대체 공휴일 표시
- 날짜에 마우스를 올리면 근무 상세와 연차 목록 툴팁 표시
- 출근 시간, 퇴근 시간, 연장 시간 표시
- 조회 중 달력 음영 처리 및 요청별 상태 토스트 표시

### 공통 UI

- `기존` / `신규` 탭 전환
- 설정 메뉴에서 인증 정보 초기화
- 다크모드 지원
- 기본 테마는 라이트모드
- 월 이동, 월 선택, 새로고침 아이콘
- 데스크톱 Chrome, Edge, Whale, Safari 환경을 고려한 브라우저 호환 설정

## 빠른 시작

### 1. 환경변수 준비

`.env.example`을 참고해 로컬 전용 `.env.local` 파일을 생성하고 값을 입력합니다.

```bash
copy .env.example .env.local
```

PowerShell이 아닌 환경에서는 다음처럼 복사할 수 있습니다.

```bash
cp .env.example .env.local
```

환경변수의 실제 값은 GitHub에 올리지 않습니다. `.env`, `.env.local`, `.env.*.local` 파일은 `.gitignore`에 등록되어 있습니다.

환경변수는 다음 그룹으로 구성됩니다.

| 그룹 | 용도 |
| --- | --- |
| `PORT` | 로컬 개발 서버 포트 |
| `REACT_APP_JADE_*` | Jade 브라우저 호출 및 응답 파싱 설정 |
| `REACT_APP_INSA_*` | 신규 인사시스템 호출 및 HTML 파싱 설정 |
| `JADE_TARGET_*` | Jade 서버 프록시 대상 설정 |
| `INSA_TARGET_*` | 신규 인사시스템 서버 프록시 대상 설정 |
| `INSA_ALLOWED_ROUTES_JSON` | 신규 인사시스템 프록시 허용 경로 설정 |

`REACT_APP_*` 값은 React 빌드 결과에 포함되므로 브라우저에서 완전히 숨겨지는 비밀값이 아닙니다. 이 프로젝트에서는 GitHub 소스에 운영 설정값이 노출되지 않도록 환경변수로 분리하는 용도로 사용합니다. Cookie와 Request Body는 환경변수에 넣지 말고 앱의 인증 화면에서 입력하세요.

### 2. 의존성 설치 및 실행

```bash
npm install
npm start
```

기본 개발 서버는 `.env.local`의 `PORT` 설정을 사용합니다. 현재 예시 설정은 3001 포트입니다.

### 3. 테스트 및 빌드

```bash
npm test -- --watchAll=false --runInBand
npm run build
```

## 인증 방법

### Jade 자동인증

1. `Jade 연결` 링크를 브라우저 즐겨찾기 바에 끌어다 놓아 저장합니다.
2. `Jade 시스템 열기`를 클릭해 Jade를 엽니다.
3. Jade에 로그인한 뒤 즐겨찾기 바의 `Jade 연결`을 클릭합니다.
4. 출퇴근관리 화면으로 이동합니다.
5. 날짜 조회 버튼을 한 번 클릭하면 연결됩니다.

주의사항:

- Jade 시스템 창을 닫지 않은 상태에서 사용하세요.
- 팝업 차단이 켜져 있으면 Jade 시스템 열기를 허용하세요.
- 연결 후 출퇴근관리 화면에서 날짜 조회를 해야 응답을 받을 수 있습니다.

### Jade 수동인증

1. Jade에 로그인하고 출퇴근관리 메뉴를 엽니다.
2. <kbd>F12</kbd> → **Network** 탭에서 정상 응답이 오는 요청을 찾습니다.
3. 요청을 우클릭 → **Copy → Copy as cURL**로 복사합니다.
4. 앱의 `cURL 붙여넣기` 탭에 그대로 붙여 넣습니다.
5. Windows PowerShell 형식은 지원하지 않으므로 `cURL (bash)` 또는 `cURL (cmd)` 형식으로 복사하세요.

cURL을 사용할 수 없으면 `Cookie + Body 직접 입력` 탭에서 Cookie와 Request Body를 각각 입력할 수 있습니다.

### 신규 인사시스템 자동인증

1. `인사 연결` 링크를 브라우저 즐겨찾기 바에 끌어다 놓아 저장합니다.
2. `인사시스템 열기`를 클릭해 신규 인사시스템을 엽니다.
3. 신규 인사시스템에 로그인한 뒤 즐겨찾기 바의 `인사 연결`을 클릭합니다.
4. 화면의 연결 안내가 끝날 때까지 인사시스템 창을 유지합니다.
5. 신규 탭 달력에 휴가와 출퇴근 정보가 표시되면 연결이 완료된 것입니다.

### 신규 인사시스템 수동인증

1. 신규 인사시스템에 로그인합니다.
2. <kbd>F12</kbd> → **Network** 탭에서 요청을 선택합니다.
3. Request Headers의 `Cookie` 값만 복사합니다. `Cookie:` 헤더 이름은 제외합니다.
4. 신규 탭의 `INSA Cookie` 입력란에 붙여 넣고 저장합니다.

인증 정보는 브라우저의 `localStorage`에 저장되며 서버에 별도로 저장하지 않습니다. 공유 PC에서는 사용 후 설정 메뉴의 `인증 정보 초기화`를 실행하세요.

## 신규 인사시스템 조회 데이터

신규 탭은 읽기 전용으로 다음 종류의 정보를 조회합니다.

| 정보 | 화면 표시 |
| --- | --- |
| 월간 일정 | 날짜별 팀 일정과 휴일 |
| 부서 연차 | `연차`, `연차 (2)`, `연차 (본인 외 2)` 등의 배지 |
| 본인 연차 | 본인 연차가 있으면 부서 연차 배지에 함께 표시 |
| 출퇴근 | 출근 시간, 퇴근 시간, 정보가 없으면 `--:--` |
| 휴일 근무 | 정규근무 정보가 없으면 휴일로 표시하되 실제 출퇴근 기록이 있으면 함께 표시 |
| 휴가 사용내역 | 본인 휴가 종류와 시간 |
| 연장근무 | 값이 있을 때만 툴팁의 `연장 시간`으로 표시 |
| 공휴일 | 달력에는 `휴일`, 툴팁에는 원본 공휴일 명칭 표시 |

마우스를 날짜 위에 올리면 근무 상세와 연차 목록을 확인할 수 있습니다. 신규 인사시스템의 월간 API, 출퇴근 API, 휴가 API 중 하나가 실패해도 가능한 데이터는 계속 표시하고 실패한 항목만 토스트로 안내합니다.

## 프로젝트 구조

```text
jade_in_out/
├── api/
│   ├── jade/[...path].js       # Jade Vercel 프록시
│   └── insa/[...path].js       # 신규 인사시스템 Vercel 프록시
├── public/
├── src/
│   ├── api/                    # API 호출 및 응답 파싱
│   ├── components/             # 기존/신규 캘린더와 인증 화면
│   ├── lib/                    # 인증 저장소, 브리지, 변환, 테마
│   ├── App.tsx
│   ├── App.css
│   └── setupProxy.js           # 로컬 개발 프록시
├── .env.example                # 값이 비어 있는 환경변수 이름 템플릿
├── package.json
└── README.md
```
