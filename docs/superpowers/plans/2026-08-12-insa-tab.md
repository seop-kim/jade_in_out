# 신규 인사시스템 탭 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 기존 Jade 화면을 유지하면서 별도 신규 탭에서 INSA의 홈 일정, 개인 출퇴근, 내 휴가 HTML을 Cookie 인증으로 조회하고 신규 달력에 표시한다.

**Architecture:** 기존 Jade 모듈은 그대로 두고 `insa` 전용 API·파서·저장소·컴포넌트를 새로 만든다. 세 HTML 데이터 소스는 날짜 키로 신규 화면 안에서만 결합하며, 팀 상세는 날짜 클릭 시 지연 조회한다. 브라우저의 CORS와 Cookie 헤더 제한은 CRA 개발 프록시와 별도 Vercel 함수 `/api/insa/*`로 해결한다.

**Tech Stack:** React 19, TypeScript 6 strict mode, Create React App 5, Jest, React Testing Library, Fetch API, DOMParser, TextDecoder(EUC-KR), http-proxy-middleware, Vercel Node serverless function

## Global Constraints

- 기존 Jade 인증, API 호출, XML 파서, 출퇴근 표시 로직과 신규 시스템 로직을 합치지 않는다.
- 신규 Cookie는 `insa_kwe_cookie_v1`에 별도로 저장하고 화면이나 로그에 원문을 출력하지 않는다.
- INSA 응답은 `ArrayBuffer`로 받은 뒤 `TextDecoder('euc-kr')`로 디코딩한다.
- 출퇴근 POST body는 `sType=0&sdt=YYYY-MM-DD&edt=YYYY-MM-DD` form-urlencoded 형식이다.
- 홈 endpoint는 `GET /main.asp`, 출퇴근 endpoint는 `POST /worktime/01_list.asp`, 내 휴가 endpoint는 `GET /leave/01_list.asp`다.
- 출퇴근 범위는 최대 한 달이고, 현재 월은 어제까지만 조회하며 미래 월에는 요청하지 않는다.
- 홈 월간 일정, 출퇴근, 내 휴가 중 하나가 실패해도 성공한 데이터는 표시한다.
- 팀 이름과 상세 일정은 날짜 클릭 시에만 조회한다.
- 휴가 신청, 출퇴근 정정, 취소 같은 쓰기 기능은 구현하지 않는다.

```ts
function directCells(row: Element): HTMLTableCellElement[] {
  return Array.from(row.children).filter(
    (child): child is HTMLTableCellElement => child.tagName === 'TD'
  );
}

export function parseInsaWorktimeHtml(html: string): InsaWorktimeRecord[] {
  const doc = parseDocument(html);
  const rows = Array.from(doc.querySelectorAll('table.tbltop tr'));
  const records = rows.flatMap((row) => {
    const cells = directCells(row);
    if (cells.length !== 14) return [];
    const ymd = cleanText(cells[3]).match(/\d{4}-\d{2}-\d{2}/)?.[0];
    if (!ymd) return [];
    return [{
      ymd,
      scheduledIn: cleanText(cells[6]), scheduledOut: cleanText(cells[7]),
      actualIn: cleanText(cells[8]), actualOut: cleanText(cells[9]),
      leaveLabel: cleanText(cells[4]), overtimeLabel: cleanText(cells[5]),
      correctionIn: cleanText(cells[10]), correctionOut: cleanText(cells[11]),
      correctionStatus: cleanText(cells[12]), note: cleanText(cells[13]),
    }];
  });
  if (!doc.querySelector('table.tbltop')) throw new Error(WORKTIME_FORMAT_ERROR);
  return records;
}
```

```ts
async function requestHtml(path: string, cookie: string, init: RequestInit, signal?: AbortSignal) {
  const response = await fetch(`/api/insa${path}`, {
    ...init,
    signal,
    headers: {...init.headers, 'X-Insa-Cookie': cookie},
  });
  if (!response.ok) throw new Error(`HTTP ${response.status}`);
  return new TextDecoder('euc-kr').decode(await response.arrayBuffer());
}

export async function loadInsaMonth(options: LoadInsaMonthOptions): Promise<InsaMonthLoadResult> {
  const worktimeRange = getWorktimeRange(options.year, options.month, options.today);
  const results = await Promise.allSettled([
    fetchInsaHomeMonth(options),
    worktimeRange ? fetchInsaWorktime(options.cookie, worktimeRange, options.signal) : Promise.resolve([]),
    fetchInsaLeave(options.cookie, options.signal),
  ]);
  return mapSettledSources(results);
}
```

```ts
export const INSA_COOKIE_STORAGE_KEY = 'insa_kwe_cookie_v1';

export function saveInsaCookie(cookie: string): void {
  localStorage.setItem(INSA_COOKIE_STORAGE_KEY, cookie.trim());
}

export function buildInsaCalendarMap(
  year: number,
  month: number,
  home: InsaHomeMonthData | null,
  worktime: InsaWorktimeRecord[],
  leaveRecords: InsaLeaveRecord[]
): InsaCalendarMap {
  const map = createMonthDays(year, month);
  for (const record of worktime) map[record.ymd]!.worktime = record;
  for (const record of leaveRecords) map[record.ymd]?.ownLeave.push(record);
  for (const summary of Object.values(home?.days ?? {})) {
    if (map[summary.ymd]) map[summary.ymd]!.teamSchedule = summary;
  }
  return map;
}
```
